YURIY BEVOV — PRODUCTION SVG PACKAGE

Файлы:

1. dev-logo.svg
   Основная версия логотипа разработчика для футера приложения.

2. logo-white.svg
   Белая версия для тёмного, цветного или фотографического фона.

3. logo-currentcolor.svg
   Версия для вставки непосредственно в HTML. Цвет задаётся CSS-свойством color.

Технические свойства:

- Надпись полностью переведена в векторные контуры.
- Внешние шрифты, изображения и сетевые ресурсы не используются.
- Фон прозрачный.
- Пропорции задаются через viewBox и сохраняются при масштабировании.
- Оптимизированный `viewBox`: `0 0 200 44`.
- Размер в интерфейсе задаётся CSS, атрибуты `width` и `height` в SVG не используются.

Пример подключения основной версии:

<img src="/dev-logo.svg" alt="Yuriy Bevov">

Не изменяйте соотношение ширины и высоты. Для футера приложения текущая ширина
задаётся классом `.app-footer__logo`.
